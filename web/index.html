Battery capacity

Override the total Wh capacity for this device — set this if you have extension batteries stacked on the host unit (e.g. 5000 Plus + 1× B5000+ = 10080 Wh). Used by the forecast SOC math; affects nothing the device itself reports.

Wh (device default: —)

Cloud properties (debug)

Raw key/value dump from the Jackery cloud for the active device. Useful to spot keys we don't yet parse — extension-battery state, per-PV-port solar, etc. 

—

Cloud endpoint probe (debug)

Tries a handful of speculative cloud endpoints (/v1/device/expansionPack, /v1/device/subDevices, etc.) to find data the iOS app uses but we don't currently parse — per-battery state, attached pack count, etc. Most will return errors; one or two might hit. Paste anything interesting back to a maintainer. 

—

Polling

The Jackery cloud only allows one active session per account. While the bridge is polling, the phone app can't stay signed in. Pause polling to hand the session over to your phone.

Account

Your Jackery credentials are encrypted on disk. Sign out to wipe them — you'll be asked to sign in again on next load.

Kasa account

—

Newer Kasa "SMART" devices (KP125M, EP25, KP405, etc.) require your Kasa cloud account credentials even for local control. Older devices (KP115, HS103) ignore them. Stored encrypted at rest in the data volume.

Smart charge

On cloudy days when the forecast says SOC won't last to sunrise, this turns on a Kasa smart plug just enough to make it through. Configured per device — switch the active device using the picker at the top to edit a different one. Test mode logs decisions but doesn't toggle the plug; use it to verify the plan is sane before going active.

Bridge events

Recent activity from the bridge — login, polling, MQTT publishes, session contests. Most recent at the top.

Debug

Ad-hoc queries against the local data store — useful for verifying the forecast / smart-charge / per-pack pipelines without leaving the dashboard. Each button writes its results into the panel below.

Runtime settings

Changes persist to /data/settings.json and apply on the next poll cycle (no restart needed). Env vars in your .env are used as defaults until you save a value here.

Display

For dashboards left open on a wall-mounted iPad / tablet — uses the browser's Wake Lock API to keep the screen from dimming while the dashboard is the active tab. Per-browser preference; turn on for kiosk setups, leave off on phones. Requires iOS 16.4+ on iPad, modern Chrome/Firefox elsewhere.

Electricity rates

Used to convert kWh into dollar savings on the dashboard. Pick a preset or enter a flat rate.
